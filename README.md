# Meu Projeto LabSIS

MoodWear é uma plataforma web que une moda e psicologia para oferecer recomendações personalizadas de estilo. A partir de informações pessoais e emocionais do usuário, o site sugere roupas que expressem identidade, humor e bem-estar, tornando a moda uma ferramenta de autoconhecimento.
